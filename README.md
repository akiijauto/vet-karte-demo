# vet-karte-demo

動物病院向け 電子カルテ・売上管理システムの **画面モック**。

👉 **[モックを開く](https://ai-l-a-b-o.com/vet-karte-demo/)**

## これは何か

AIエージェントを用いて単独で開発しているシステムについて、
**画面と設計判断を見ていただくために作った静的なページ**です。

- **これは設計を画面に起こしたモックで、動くシステムではありません。**
  動くのはページ間のリンクだけで、入力・保存・検索はできません。
- **実システムのソースコードは含みません。**
- 表示しているデータは**すべて架空**で、実在する動物病院・飼い主・動物の情報は一切含みません。
- **外部への通信を行いません。** JavaScript も使っておらず、読み込むのは同梱の `style.css` だけです。

## 画面

実物と同じ画面構成で、**ページ間のリンクが実際に動きます**。

| ページ | 内容 |
| --- | --- |
| `index.html` | 説明（解こうとしている問題／設計判断／検出した不具合） |
| `list.html` | **外来受付** — その日に来ている患者を一望する。ここが1日の起点 |
| `owner.html` | **顧客** — 飼主と動物。1人の飼主に複数の動物がぶら下がる |
| `karte.html` | **診察カルテ** — 稟告・現症・処置。紙カルテと同じ書式で印刷できる |
| `exam.html` | **検査** — 13項目の検査値と基準値。範囲外は判定欄と色の両方に出す |
| `accounting.html` | **会計** — 18分類の明細と合計 |
| `ward.html` | **入院** — 在院一覧・経過表・投薬スケジュール |
| `reservation.html` | **予約** — 担当と処置室の両方で埋まり具合を見る |
| `sales.html` | **売上集計** — 会計の明細から積み上げる |

## 何を見ていただきたいか

機能の数ではなく、**「AIに業務システムを作らせるとき、品質をどう担保するか」**です。

受付から会計までの各段階で「何が満たされていれば正しいか」を先に定義し、
AIに自己検証させたうえで人が確認する手順にしました。
金額の算定・計上に関わる箇所は、AIの出力をそのまま採用せず**検算が通ることを採用条件**としています。

その検証で**実際に検出した不具合を2件**、説明ページに載せています。

1. **全患者のカルテに同じ体温が印字されていた** — 写し漏れた固定値。印刷の点検項目が用紙からの逸脱に寄っており、
   値の正しさは対象外だった。固定値の不在を全患者 × 画面／印刷の **252ページ**で自動検証する項目を追加して対処
2. **合計額が単価未設定の行を0円として集計していた** — 合計を伏せるのではなく、**未算入の行数を明示する**仕様に是正

## モック自身の整合性

「3つの数え方が一致すること」「実施者が空の行を作らないこと」を画面の中で主張している以上、
**モックの数字がそれを破っていては意味がない**ので、機械的に確かめてあります。

- 売上集計：**分類別・担当別・日別の3方向とも 6,384,000 円**で一致（構成比の和も 100.0%）
- 入院：投薬・給餌・計測の記録行で、**実施者が空の行は0件**
- 検査：範囲外の3項目は判定欄（H/L）と色の**両方**に出ており、範囲内の10項目にはどちらも付かない
- 予約：担当3名・処置室2室それぞれで時間の帯を突き合わせ、**重複0件**
- 外来一覧と予約表で、同じ患者の時刻が**食い違わない**ことを照合済み
